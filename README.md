# 📐 Numerical Analysis Algorithms with Python

A collection of **Numerical Analysis algorithms and methods implemented in Python**, covering numerical solutions of equations, systems, interpolation, numerical integration, differentiation, and other fundamental computational techniques.

## 📖 Overview

This repository is dedicated to learning and implementing **Numerical Analysis methods through Python programming**.

Each method is implemented based on its standard mathematical algorithm, making the code useful for understanding both the **theory and practical implementation** of numerical methods.

## 📚 Topics Covered

### 🔹 Algebraic & Transcendental Equations

- Bisection Method
- False Position Method
- Fixed Point Iteration Method
- Newton-Raphson Method
- Secant Method

### 🔹 Solution of Linear Equations

- Gauss Elimination Method
- Gauss-Jordan Method
- Gauss-Seidel Method
- Jacobi Iteration Method

### 🔹 Interpolation

- Newton Forward Interpolation
- Newton Backward Interpolation
- Lagrange Interpolation
- Newton Divided Difference

### 🔹 Numerical Differentiation & Integration

- Numerical Differentiation
- Trapezoidal Rule
- Simpson's 1/3 Rule
- Simpson's 3/8 Rule

### 🔹 Numerical Solution of Differential Equations

- Euler's Method
- Modified Euler's Method
- Runge-Kutta Methods
